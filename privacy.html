Privacy Policy

Clipper · last updated 28 September 2026

Clipper is a personal utility operated by one person for their own use. It is not offered to the public and has no users other than its operator. This policy describes how it handles information, which is: as little as possible.

Information collected from you

None. Clipper has no sign-up, no accounts, no cookies, no analytics, no tracking, and no server that members of the public interact with. This website is a set of static pages and collects nothing from visitors.

Google user data it accesses

When its operator authorises it, Clipper receives an OAuth token for a single Google account — the operator's own — under one scope:

  • https://www.googleapis.com/auth/youtube.upload — permission to upload a video to that account's YouTube channel.

This scope allows uploading only. Clipper cannot read the channel's videos, analytics, comments, subscribers, playlists, or any other account information, and it does not request any scope that would allow it to.

How that data is used

The token is used for exactly one operation: uploading a video file the operator has produced to the operator's own YouTube channel, together with its title and description. It is used for no other purpose.

Storage and retention

The OAuth token is stored only on the operator's own computer, in a local file readable solely by the operator's user account. It is never transmitted anywhere except to Google's own API endpoints during an upload. It is retained until the operator revokes it or deletes the file.

Sharing

Clipper transfers Google user data to no one. There are no third parties, no service providers, no advertisers, and no analytics vendors. Clipper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The operator can revoke Clipper's access at any time at myaccount.google.com/permissions, which immediately and permanently invalidates the stored token. Deleting the local credential file has the same practical effect.

Children

Clipper is not directed to children and is not used by anyone other than its operator.
